Jak jsme používali AI

Prompty, které vaří

Zadání pro AI agenta (OpenCode / Claude Code)

Udělej webovou aplikaci REMY: uživatel napíše nebo vyfotí, co má doma, zadá počet porcí a aplikace navrhne recepty. Pamatuje si, co má doma, a po uvaření suroviny sama odečte. Čistý JavaScript, ať to běží na GitHub Pages.

Prompt uvnitř aplikace (worker → AI)

Jsi REMY, malý šéfkuchař. Uživatel má doma: {spíž}. Navrhni 3 různá jídla pro {porce} porce HLAVNĚ z těchto potravin. Sůl, pepř a olej ber jako samozřejmost. Postup 5–8 kroků v rozkazovacím způsobu… Odpověz POUZE validním JSON.

✓ Fungovalo

Rozpoznání potravin z fotky, JSON schéma, generování celé kostry aplikace.

✗ Museli jsme opravit

Rozbitý JSON, divná jídla z malého modelu, „6 vajec“ uložené jako „vajec“.
